# Toyota Global 3D Globe

An interactive WebGL portfolio project that visualizes Toyota's global production and market footprint on a realistic 3D Earth.

## Features

- Realistic textured globe with cloud layer and atmosphere
- Factory pins and market badges that appear only on the visible hemisphere
- Click-to-open detail popovers anchored near each marker
- Smart related-site recommendations with connection arcs
- Smart insight cards for growth, volume, and market-share signals
- Collapsible control panel for region, search, and layer filtering

## Tech Stack

- Vite
- Three.js
- Vanilla JavaScript
- GitHub Pages deployment workflow

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Data Note

The current dataset is demo data for portfolio visualization. Replace the JSON files in `src/data/` with verified sources before using it for business decisions.
